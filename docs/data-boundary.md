# Public/private data boundary

## Allowed in public cloud

- Website content and public product descriptions
- Public documentation
- Public status and health metadata
- Public release metadata and explicitly approved downloads
- Public contact metadata

## Prohibited in public cloud

- The five Cognitive Stores
- Private memory or private Owner data
- PNC private source archives or raw research conversations
- API keys, credentials, secrets, tokens, or production signing keys
- Canonical transactional databases
- Private source code or personal documents
- Unrestricted PC control, file browsing, shell access, or private Meo state

## Review rule

Every new cloud feature and every new public artifact must be checked against this boundary before deployment. Ambiguous data remains local and private.
